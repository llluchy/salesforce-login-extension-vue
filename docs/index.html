One extension for all your Salesforce login needs

不再需要在不同 org 之间反复输入密码、切换认证器、掏出手机扫码。以下六项核心能力覆盖了日常开发、测试和管理的全部场景。

一键登录

One-Click Login

点击即登录任意 Salesforce 环境（生产、沙箱或自定义域名）。自动检测 SOAP API 可用性，不可用时降级为表单登录。

Instantly log into any Salesforce org (Production, Sandbox, or custom domain). Automatically falls back to form-based login when SOAP API is unavailable.

🔒

Passkey / WebAuthn

Passkey / WebAuthn

自动拦截 Salesforce WebAuthn 验证请求，使用本地存储的 ECDSA P-256 密钥完成签名。无需安全密钥或手机，纯软件实现。

Automatically intercepts Salesforce WebAuthn prompts and signs challenges with locally stored ECDSA P-256 keys. Pure software implementation — no hardware key needed.

⏱

内置 TOTP 验证器

Built-in TOTP Authenticator

扫描二维码或手动输入密钥，直接在插件内生成时效验证码。无需第三方认证器 App，支持复制验证码和自动显示剩余有效秒数。

Scan QR codes or manually enter secrets to generate TOTP codes directly in the extension. Copy to clipboard with remaining validity countdown.

📤

端到端加密云同步

E2E Encrypted Cloud Sync

所有凭证使用 AES-256-GCM 在本地加密后再上传。密钥由 PBKDF2-SHA256（100,000 次迭代）从主密码派生，服务端永远无法解密。

All credentials are encrypted with AES-256-GCM before upload. Keys derived from your master password via PBKDF2-SHA256 (100K iterations). Servers can never decrypt your data.

📦

环境管理与分组

Environment Management

自定义别名、拖拽排序、分组管理数十个 Salesforce 环境。支持生产、沙箱、自定义域名三种类型，一键切换。

Custom aliases, drag-and-drop sorting, and grouping for dozens of orgs. Production, sandbox, and custom domain types all supported.

🤝

环境分享

Environment Sharing

通过分享码安全分享环境凭证给团队成员。数据使用一次性临时密钥加密，只有指定的接收者可以解密。分享码使用后自动失效。

Share environment credentials securely via share codes. Data encrypted with one-time ephemeral keys. Share codes auto-invalidate after use.

使用流程
How It Works

三步开始，一键登录

Three steps to get started

  1. 初始化保险库

    Set Up Your Vault

    注册账号并设置主密码。AES-256 加密密钥在本地通过 PBKDF2 派生，永不发送至任何服务器。你的数据，只有你能解密。

    Create an account and set your master password. Your AES-256 encryption key is derived locally via PBKDF2 and never sent to any server. Only you can decrypt your data.

  2. 添加 Salesforce 环境

    Add Salesforce Environments

    输入用户名、密码和安全令牌，选择环境类型（生产/沙箱/自定义域名）。凭证在保存前即被 AES-256-GCM 加密。

    Enter username, password, and security token. Select environment type. Credentials are encrypted with AES-256-GCM before storage.

  3. 一键登录

    One-Click Login

    点击任意环境的登录按钮，新标签页直接打开已认证的 Salesforce 页面。遇到 Passkey 验证时，插件自动处理。

    Click login, and a new tab opens directly to your authenticated Salesforce org. When Passkey verification is triggered, the extension handles it automatically.

  4. Passkey 自动验证

    Passkey Auto-Verification

    当 Salesforce 要求 Passkey 验证时，插件自动弹出环境选择框。选择匹配的环境后，插件用本地存储的 ECDSA P-256 私钥对 challenge 签名并返回。

    When Salesforce requests Passkey verification, the extension shows an environment picker. Select the matching environment, and the plugin signs the challenge with your locally stored ECDSA P-256 private key.

Tech Stack

构建技术栈

Built With

⚙

Chrome Extension Manifest V3

基于最新的 Chrome 扩展平台，包含 Service Worker、Side Panel、Content Script 三层架构。

Built on the latest Chrome Extension platform with Service Worker, Side Panel, and Content Script layers.

Vue 3 + Vite + CRXJS

使用 Vue 3 Composition API 构建 Side Panel UI，Vite 负责编译打包，CRXJS 桥接 Chrome Extension 开发流程。

Vue 3 Composition API for the Side Panel UI, Vite for building, and CRXJS for bridging the Chrome Extension development workflow.

🔒

AES-256-GCM + PBKDF2

客户端加密使用 Web Crypto API。密钥通过 PBKDF2-SHA256（100,000 次迭代）从主密码派生，数据以 AES-256-GCM 独立 IV 加密。

Client-side encryption via Web Crypto API. Keys derived from master password using PBKDF2-SHA256 (100K iterations). Data encrypted with AES-256-GCM with unique IVs.

☁

Supabase

后端使用 Supabase 提供身份认证、加密数据存储和 Row Level Security。所有数据受 RLS 策略保护，auth.uid() = user_id。

Backend powered by Supabase for authentication, encrypted data storage, and Row Level Security. All data protected by RLS policies: auth.uid() = user_id.
